# Gemini in Collaborate.asciidoc

Follow [AGENTS.md](AGENTS.md), the single instruction file shared by all agents. It contains the repository map, safety rules, and workflow.

Before every push, verify with `scripts/check.sh` (exactly what the required `go-verify` check runs). Read [`docs/ENGINEERING-NOTES.md`](docs/ENGINEERING-NOTES.md) before a non-trivial change. Work on a `gemini/` branch, open a draft PR with `Collaborate-Claim:` lines, and never merge your own PR.
